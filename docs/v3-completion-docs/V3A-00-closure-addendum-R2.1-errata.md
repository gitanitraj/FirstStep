- **Rows F-01, F-02, F-05 to F-07 and S-06** cite §4A.2. These citations are correct for the routes they describe.
- **Other unprefixed "C-02 closure" citations.** These appear in the §2 ledger and in §4 rows N-01, N-02, N-03, N-06 and N-08. They are outside E-1, and no contract C-02 criterion appears in those sections, so the ambiguity is low. They are not corrected here. Where they appear, read them as V3A00-C-02.

- **The Implementation Framework uses a different convention.** It writes "audit C-01" and "P02/C-01" (framework §5). That convention and R2's `V3A00-` prefix are equivalent. R2 and this note keep R2's convention.
